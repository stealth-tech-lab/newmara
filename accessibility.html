Accessibility

A digital experience designed to be usable.

Newmara seeks to make its public website accessible to a broad range of visitors and to improve usability as the site evolves.

Our Approach

Accessibility is an ongoing process.

We consider readability, keyboard access, semantic structure, contrast, descriptive labels, responsive layouts, and compatibility with common assistive technologies as part of maintaining the website.

Clear structure

Pages use headings, labels, navigation, and content hierarchy intended to make information easier to understand.

Responsive design

The website is designed to adapt across common desktop, tablet, and mobile screen sizes.

Feedback

If you encounter an accessibility barrier, we want to know about it.

Need Assistance?

Tell us what is not working.

If you have difficulty accessing information or using a feature on this website, please use the Newmara contact form and describe the page, feature, and issue you encountered.
